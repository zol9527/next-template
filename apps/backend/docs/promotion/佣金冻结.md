# 冻结状态 (frozen) 详解

根据代码探索，冻结状态 (frozen) 是佣金管理的核心风控机制：

主要作用

1. 风险控制
    - 订单支付成功后，佣金先进入冻结状态，而不是立即可结算
    - 给予平台审核和退款处理的时间窗口
    - 防止推广员在订单可能退款的情况下就提现佣金
2. 生命周期流程
订单支付 → 佣金冻结 (frozen) → 订单完成 → 可结算 (payable) → 结算中 → 已结算
3. 冻结期间的限制
    - 不能结算: 只有 payable 状态的佣金才能参与结算
    - 不能提现: 冻结状态无法提现到推广员账户
    - 支持退款调账: 冻结状态的佣金可以随订单退款而调整金额或作废

自动流转逻辑

| 触发条件     | 状态变化                        |
|--------------|---------------------------------|
| 订单支付成功 | 创建冻结状态佣金 (frozen)       |
| 订单完成     | frozen → payable (可结算)       |
| 发生退款     | 调整冻结佣金金额或标记为 voided |

代码位置

- 创建冻结佣金: src/services/commission.service.ts:137

这种设计确保了佣金只有在订单真正完成且无退款风险后，才能进入结算流程，是分销系统的标准风控实践。
